# Cozy Yarn Tracker v4

Modular structure for easier iteration:

- `index.html` — app markup
- `css/styles.css` — theme and layout
- `js/app.js` — application behavior and local data
- `assets/icons/` — Home Screen and PWA icons
- `manifest.webmanifest` — install metadata
- `sw.js` — offline cache

Upload the **contents** of this folder to the repository root, preserving the folders.
